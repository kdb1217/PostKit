## 📑 App Introduction

  PostKit은 쉽고 빠른 마케팅 글쓰기를 도와주는 앱입니다.


**Feature 1**  
- 키워드를 입력하면, 해당 키워드에 맞춰서 인스타그램 홍보글을 작성해줍니다

**Feature 2**
- 이미지를 입력하면, 이미지에 기반하여 인스타그램 홍보글을 작성해줍니다.

**Feature 3**
- 생성된 홍보글들을 저장하고 확인할 수 있습니다.
